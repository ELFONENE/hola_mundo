Cómo está construida esta web

Esta misma web puede construirse de dos formas distintas y mostrar prácticamente el mismo resultado en pantalla. Aquí puedes comparar las dos estructuras.

1. Dos formas de construir la misma web

Modo simple · un solo archivo

simple/
└── index.html
    ├── HTML
    ├── <style> CSS </style>
    └── <script> JavaScript </script>

La versión SIMPLE reúne su estructura, estilos y programación en un único HTML.

Modo completo · páginas y archivos separados

completa/
├── inicio.html
├── blog.html
├── contacto.html
├── style.css
└── script.js

La versión COMPLETA utiliza páginas HTML independientes y comparte CSS y JavaScript externos.

2. Qué hace cada lenguaje

HTML crea y organiza el contenido de la página: títulos, textos, imágenes, enlaces, formularios y demás elementos.

CSS controla la presentación visual: colores, tamaños, tipografías, espacios, posiciones y adaptación a distintos tamaños de pantalla.

JavaScript añade comportamiento e interacción: responde a acciones del usuario y ejecuta funciones de la página.

Para seguir aprendiendo: al final del tutorial encontrarás documentación y cursos externos.
