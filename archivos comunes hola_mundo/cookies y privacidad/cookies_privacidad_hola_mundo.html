2. Política de privacidad

HOLA MUNDO no incorpora cuentas de usuario, pagos ni una base de datos propia para almacenar datos personales.

2.1. Contacto voluntario

El formulario de contacto utiliza mailto:. Al enviarlo, el navegador intenta abrir el programa o servicio de correo configurado por el visitante. El contenido no se envía a un servidor propio de HOLA MUNDO.

2.2. Datos técnicos

Cuando la web se publica mediante un servicio de alojamiento como GitHub Pages, dicho proveedor puede tratar datos técnicos necesarios para servir la página y mantener la seguridad, conforme a sus propias condiciones y políticas.

2.3. Derechos y contacto

Las consultas relacionadas con esta web pueden enviarse al correo indicado en la ficha del responsable. Cuando resulte aplicable, el usuario puede ejercer los derechos previstos por la normativa de protección de datos.

4. Gestión del consentimiento

HOLA MUNDO utiliza un panel propio y didáctico. Como el sitio no activa preferencias opcionales, analítica ni marketing, el panel muestra esas categorías desmarcadas y deshabilitadas, mantiene las necesarias/técnicas como única categoría activa e informa del uso técnico para guardar o borrar esa elección.

La configuración puede reabrirse desde aquí o desde el enlace Configurar cookies situado en el pie de las páginas.

HOLA MUNDO es una web de demostración y aprendizaje. Sus ejemplos pretenden enseñar estructura, estilos, JavaScript, rutas, navegación y organización de archivos.

Los ejemplos pueden cambiar a medida que evoluciona el proyecto. Los enlaces externos se facilitan como referencia y cada sitio de destino es responsable de sus propios contenidos, condiciones y políticas.
